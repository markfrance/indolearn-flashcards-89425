# DEPRECATED: Local Database

This directory previously contained scripts and Docker-like helpers for running a local PostgreSQL instance and seeding data.

The project has been migrated to Supabase. Do not use these scripts. No local seeding is required.

Use Supabase for:
- Authentication
- Flashcard, category storage
- Optional: server-side spaced repetition and stats

See `assets/supabase.md` at the repository root for the current database schema and setup instructions.
